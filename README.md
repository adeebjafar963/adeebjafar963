## 🚀 Featured Project

### 🏋️ OctaFit — AI-Powered Sports Platform

OctaFit is my graduation project: a sports mobile application designed to bring training, fitness shopping, and AI-powered sports assistance together in one platform.

**Key Features:**

- 📱 Cross-platform mobile application built with Flutter.
- 🛍️ Sports e-commerce store.
- 💪 Workout and exercise learning resources.
- 🤖 AI Coach for sports questions and personalized training and nutrition plans.
- 🩺 AI Physiotherapist for initial guidance and exercise recommendations.
- 🎥 Motion analysis to help users improve their exercise technique.
- 🌐 Arabic and English language support.
- 👥 Community features for posts, stories, and likes.

**Technology Stack:**

`Flutter` · `Dart` · `Laravel` · `PHP` · `MySQL` · `Python` · `FastAPI` · `REST APIs`

> This project reflects my interest in combining software engineering, mobile development, and artificial intelligence to create practical solutions.
